EdTech Content Delivery Modality & Statistical Testing Standards

Platform Optimization Research Documentation | Senior Product Data Scientist

1. Empirical Content Modality Completion Baselines

Empirical benchmarks across digital learning platforms (Coursera, MOOC research, Duolingo) indicate that traditional long-form video lectures suffer catastrophic attrition within the first 6–10 minutes. Breaking curriculum into modular chunks with formative retrieval checkpoints significantly increases course completion and conceptual retention.

Delivery Format Format Description Industry Baseline Completion Cognitive Drivers & Funnel Dynamics
Control (Long Video) Monolithic 30–50m lecture video 10% – 20% Severe attention decay after 6m; high passive multitasking and drop-off.
Variant B (Micro-Video) Chunked 3–6m modular videos 65% – 75% Low friction per session; accommodates fragmented daily learner schedules.
Variant C (Micro-Quiz) Micro-video + in-video mini quizzes 75% – 85% Active recall testing effect; formative commitment prevents dropout.
Variant D (Shorts + Project) 60–90s shorts + take-home project 25% – 42% High initial watch rate, but submission barrier induces steep mobile drop-off.

2. Primary Hypothesis Formulation: Two-Sample Proportion Z-Test

To evaluate whether Challenger Variants (B, C, D) produce statistically significant uplifts in Module Completion Rate over Control (A):

H0: p_variant = p_control vs H1: p_variant > p_control

Z = (p_variant - p_control) / sqrt( p_pool * (1 - p_pool) * (1/n1 + 1/n2) )
where p_pool = (x_control + x_variant) / (n_control + n_variant)

Target Significance Level: α = 0.01. Minimum Detectable Effect (MDE) with N=1,000 per arm: 4.8% (at 80% statistical power).

3. Multiple Testing Correction: Bonferroni & Holm Step-Down

Because 3 challenger variants are evaluated simultaneously against a single control, testing each arm at unadjusted α = 0.01 inflates Family-Wise Error Rate (FWER) to 1 - (1 - 0.01)^3 ≈ 0.0297 (~3%).

  • Standard Bonferroni: α_adj = α / k = 0.01 / 3 = 0.0033
  • Holm-Bonferroni (Step-Down): Rank p-values p(1) ≤ p(2) ≤ p(3). Test p(i) ≤ α / (k - i + 1). Thresholds: 0.0033, 0.0050, 0.0100.

4. Secondary Hypothesis: Welch's t-Test for Knowledge Retention

Post-assessment scores (0–100) exhibit unequal variance across formats due to varying degrees of active participation. Standard Student's t-test assumes homoscedasticity; therefore, Welch's t-test with Satterthwaite degrees of freedom is required:

t = (x̄_variant - x̄_control) / sqrt( s1^2 / n1 + s2^2 / n2 )
